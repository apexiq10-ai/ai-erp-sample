# Rillet · The system of proof

A focused, cinematic, two-scene Rillet product marketing concept. Runway-generated 3D motion carries the experience; HTML, CSS, and JavaScript provide readable copy and navigable evidence.

## Start here

1. Open `MASTER_PROMPT.md` and give it to the AI builder with this package.
2. Use `embed/rillet-scenes.html`, `embed/rillet-scenes.css`, and `embed/rillet-scenes.js` as the three drop-in source files.
3. Keep `embed/heroics-ledger-monolith.mp4` and `embed/bring-your-last-close.mp4` beside them. These are the packaged Runway assets.

`dist/` is a standalone copy of the same experience for static hosting and preview. No build step, API key, or framework is required. The two scenes navigate by index, arrows, wheel, swipe, and keyboard. The evidence and Parallel Close views are interactive. The films are muted and the experience has a motion toggle and static fallback.

## Other files

- `STRATEGY.md`: positioning and launch context.
- `RUNWAY_ASSETS.md`: motion-file provenance and usage notes.
- `MASTER_PROMPT.md`: executable handoff for the AI builder.

This is an independent proposal. Its 3D visuals and sample figure are illustrative, not customer or product data. The typographic Rillet header is a placeholder for an approved official logo.
